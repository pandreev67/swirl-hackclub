## My Dream Garage 🏎️

A simple website built for Hack Club Swirl featuring two of my favorite cars: the Dodge Challenger SRT Demon 170 and the McLaren 720S.

## Features

- Dark / Light mode toggle with localStorage memory and anti-flicker script
- Multi-page site structure index.html, dodge-challenger.html, mclaren-720s.html
- Custom 404.html error page
- Car performance specification tables <table>
- Unified footer with links to Hack Club Swirl, GitHub, and email
- CSS custom properties (variables) for theme switching
- Inline SVG race car emoji favicon 🏎️
- Unique <title> and <meta description> tags on every page

## Languages Used

- HTML
- CSS
- JavaScript
